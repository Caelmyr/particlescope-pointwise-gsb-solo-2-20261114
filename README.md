# 粒境 ParticleScope 2.0

显微图像颗粒分割、形态测量与定量分析工作台。适用于对比清晰的微球、粉末、纤维、荧光颗粒和材料截面照片。采用独立编写的图像分析业务，不复用 PaperFlow 的扫描、OCR、PDF编排或档案处理链。

项目按“自有后端有效代码超过5000行、至少10项可操作功能”建设。精确统计及逐文件SHA见 `docs/line-count.json`，功能入口与验收步骤见 `docs/功能清单与页面验收.txt`。代码统计不包含前端、测试、脚本、依赖、虚拟环境、注释、空行、文档字符串和纯字符串正文。

## 启动

本机需要 Python 3.12+，首次安装依赖需要网络，处理过程完全本地：

```bash
bash start.sh
```

打开 http://127.0.0.1:8894 。`Ctrl+C`停止。端口可用 `PORT=8895 bash start.sh` 指定；`PARTICLESCOPE_DATA_DIR`可指定独立数据目录，默认本项目data。已有虚拟环境会按requirements的哈希更新依赖。

Windows安装Python 3.12后双击 `start.bat`，关闭服务终端或按Ctrl+C停止。Windows启动脚本未在Windows实机验证。

Docker：

```bash
docker compose up -d --build
```

停止 `docker compose down`。映射到127.0.0.1:8894，data挂载持久化。本轮未实际构建Docker镜像，不把配置存在视为容器验证通过。

## 主要功能

1. 多图导入、样本搜索、标签、说明、项目分组、复制和可恢复归档。
2. 六种合成演示图，包含离散、粘连、非均匀照明、荧光、纤维和多孔材料，附二值参考掩膜。
3. 图像画布缩放、平移，原图、当前图像、掩膜、实例标签和叠加图切换。
4. 矩形、多边形ROI，按有效分析面积归一化覆盖率与密度。
5. 像素/微米/毫米/纳米标定；几何处理后重置标定，防止误用比例。
6. 手动、Otsu、局部自适应、分位数四种阈值分割，支持七种颜色通道。
7. 平滑、开闭运算、填孔、面积筛选、边缘排除和连通性选择。
8. 距离种子分水岭分离粘连颗粒。
9. 画布多边形添加/擦除掩膜，点选移除颗粒和连接颗粒；保存新分析记录。
10. 面积、等效直径、Crofton周长、轴长、Feret径、偏心率、实心度、灰度等逐颗粒测量。
11. 按测量范围和人工编号筛选，保留排除原因与未筛选检测，更新覆盖率和叠加。
12. 图像预处理：去噪、拉伸、Gamma、背景校正、锐化、均衡、通道提取及几何操作；可恢复历史。
13. 线段、角度、多边形和点标注，自动标定长度/面积，叠加显示与CSV导出。
14. 灰度剖面、通道直方图、清晰度、曝光与照明质量诊断。
15. 数量/面积/等效球体积加权粒径分布、D10/D50/D90、方向分布、相关性、异常值和回归。
16. 自定义粒径分级、独立重采样与空间块重采样、边界敏感性、标定误差传播及抽样精度估计。
17. 最近邻、ROI边缘距离、格网密度、环带密度、密度聚类、径向对分布和Ripley K探索。
18. GLCM、局部二值模式、梯度方向、多尺度细节和径向功率谱。
19. RGB/Lab颜色统计、主色聚类、色差匹配和荧光扣背景定量。
20. 孔隙率、内切厚度、盒计数、形态学颗粒谱、阈值拓扑及细化骨架。
21. 参考掩膜IoU/Dice、边界距离、边界容差F1与连通对象匹配。
22. 双样本分布比较、分析版本掩膜比较和多样本汇总。
23. 平移配准、控制点仿射配准与羽化拼接，生成独立新样本。平移配准对相位相关的多个候选在真实重叠区内做空间域复核，输出可靠/歧义/证据不足三种结论：周期排列微球错开整排等多义位移会列出候选要求人工核对，无重叠或低相关拒绝另存，白色填充不计入相似度且在另存样本上以警示斜纹标出。
24. 分析配方、配方导入导出、批处理进度、取消、失败重试和重启中断状态。
25. 测量热图、透明颗粒裁片、颗粒图册、CSV/JSON/GeoJSON/TIFF/ZIP和可打印报告。

页面“分析工具箱”可进入统计、空间、形态、颜色、纹理和精度工具；不是只有接口的功能列表。较长数据表页面限制显示条数，完整结果可下载JSON或CSV。

## 数据与版本

`data/samples/<id>/`保存原图、工作图、缩略图、元数据、图像历史、标注、参考掩膜及各次分析。分析的标签矩阵、二值掩膜、叠加图和结果分目录保存。配方、项目和批任务分别保存于对应目录，JSON采用临时文件和os.replace写入。

图像预处理、修改ROI或标定会清除当前分析选择，要求重新分析。历史分析仍保留，但不能把不同图像版本或不同ROI/标定的结果直接设为当前。几何操作和恢复图像同时清除人工标注、ROI及标定。掩膜修订保留未涉及的已分离实例。测量筛选另存分析版本，不覆盖原始检测。

只运行一个服务进程写同一data目录；进程内用锁串行化修改。多线程HTTP服务不等于支持多进程共享写入。批处理每次处理一个样本；取消在当前样本结束后生效，已完成步骤不回滚。队列中样本若被修改，会明确失败而非覆盖。重启把未结束任务记为interrupted，已完成结果保留。

上一版直接位于data下的样本首次启动会复制导入新格式，旧目录原样保留；不把旧引擎测量伪装成新结果。迁移映射见legacy-imports.json。

## 测量边界

所有坐标以图像左上为原点，X向右、Y向下。面积为分割像素数乘比例平方，等效直径为同面积圆直径。周长为Crofton近似；凸包和Feret径基于离散边界；小颗粒误差较大。二维粒径不是三维粒径，体积加权依赖等效球假设。粘连分离依赖种子间距和形状，必须人工检查。

径向对分布和K函数采用全图矩形观察窗、未做边缘修正，不宜用于不规则ROI的严谨随机性推断。所有颗粒统计不能替代独立实验重复。频谱、骨架、扫描和自动配准限400万像素。双边滤波同限400万像素。最多20000个颗粒；图册与裁片最多600个；分割图像最大1600万像素；导入每次最多20个文件、请求体最大96MB。当前没有登录、多用户隔离、GPU模型和自动三维重建功能。

## 验证

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/count_lines.py
node --check static/app.js
```

结果见 `docs/test-output.txt` 和 `docs/验收记录.txt`。单元与集成测试使用独立临时data，不污染用户样本。功能验收文件区分已做接口验证与已做页面观察，不把二者混同。

技术栈：Python、Flask、Pillow、NumPy、SciPy、scikit-image、Waitress、原生HTML/CSS/JavaScript。scikit-image仅提供分水岭算子，第三方代码不计入自有后端行数。

## 轮廓矢量导出

“导出与报告”提供颗粒轮廓 SVG。它逐实例保留未经简化的完整栅格边界，以 even-odd 填充表达孔洞，标记颗粒编号，并使用图像像素坐标。路径节点数较多，适合用作几何核对的原始矢量结果。
